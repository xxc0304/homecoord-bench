# 时延方向能否成为核心命题：研究可行性判断

2026-10-06。本判断承接用户要求：先仔细研究方向，再有条件设计小规模验证。不更换原项目的多Agent冲突—服务—时延主问题。文献判断不是独立审查、查新证明或录用预测；新试点不继承旧版本验收。

## 1. 结论与需要收紧的上一轮表述

**可以作为有条件推进的候选核心问题；当前还不能把它认定为达到顶会要求的核心贡献。** 上一轮“跨过执行窗口是更有创新性的深化点”应收紧：它是更聚焦的实验问题，不等于新现象。非抢占阻塞、在线承诺、执行余量、异步推理造成状态陈旧，都已有基础。

如果工作止于两个家庭标签案例、展示延迟过大导致排队、添加时间分解字段，没有足够的独特性。更值得尝试的贡献组合是：形式化可修改窗口与命令生效窗口；在同信息/权限/提案/执行合同下干预时间与协调机制；提出运行前可检验的预测，并保留预测失败、负对照和个体代价；最后在不同独立控制结构和实际耗时下检验预测是否有迁移价值。benchmark论文不必强行发明新LLM算法，但需要新的诊断能力、非平凡发现与足够广泛的实验支持。

## 3. 建议的候选命题与可证伪形式

候选问题：**多Agent异步协调中的冲突—时延取舍，能否由决策延迟与可修改执行窗口的匹配预测，而不只由平均耗时或最终调度质量解释？**

当前子假设：在固定非抢占前缀、容量、提案与EDF的F2合同中，未启动预约的重排效应依赖审议完成时的真实执行阶段。延迟可能被资源等待吸收、使命令实际启动线性后移，或在原预约实际开始后失去重排机会。改变water的等待可能推迟其他任务，不自动提高全户完成或安全性。

需明确两种边界：设提案就绪时刻P、原阻塞预约启动B、命令时长L、额外共同审议时长d。本试点中的可撤销边界为d<=B-P（同刻phase3审议先于phase4启动）；吸收至原可用资源时刻还要求d<=B-P-L。B-P不是通用期限余量；只靠一个d/窗口比值也不能预测所有DAG、设备资源组合或失败机制。

**单纯预知不可抢占会阻塞是经典效应。** 新研究的价值门槛是：上述诊断比单一开销/最终得分提供可迁移、可证伪的解释，且不是人工选边界后得到的循环论证。新试点仅检验必要的机制前提，不跨过这个门槛。

## 4. 顶会候选贡献的推进/停止门槛

| 门槛 | 当前准备度 | 后续必须做什么 |
| --- | --- | --- |
| 与已有工作的明确差异 | 有上述重合清单，尚无独占创新证明 | 系统比较其控制变量、时间合同、机制识别与预测能力；若已被覆盖则缩为子分析，不包装新benchmark核心。 |
| 可证伪预测而非事后图解 | 旧F2提供预约效应及100ms局部控制；边界单元测试已存在 | 新试点预测先保存，所有固定网格结果公开，失败不能调阈值抹去。 |
| 多Agent问题的必要性 | 本F2是多提案共享资源，但不证明分布式信息必不可少 | 相同提案/到达流的普通在线排程对照；若多Agent语义没有增量，明确定位为执行协议诊断，而非新多Agent算法。 |
| 跨结构与实际相关性 | 两个F2模板不是两个独立机制；当前耗时为合成 | F1等待/排序与至少另一独立有效机制；实际延迟分布与有依据的事件余量，保留远离边界配置。 |
| 实验质量与证据量 | 已有实现审查帮助保证计分正确，但不是命题验证 | 新入口独立复审、前瞻留出、真实调用与执行时钟校准；样本量按独立结构与真实重复定义，不按网格点凑显著性。 |

若小试点只复现已知非抢占排程效应，可保留为原benchmark的机制说明，但**不足以据此宣布顶会竞争力**。若在真实耗时/合理余量下长期无效，不应放大规则耗时制造收益。当前不新增模型预算、不读取保留集、不引入新快慢算法，也不更换研究主线。

## 5. 本轮授权内的小验证

条件式进入一个F2“延迟×预约处理×窗口位置”开发试点，详见 `LATENCY_WINDOW_PILOT_V1_PREREG_2026-10-06.md`。原发布世界保留；近窗口世界按旧早期预约结构事前构造，仅作为合成诊断。复用已有显式引擎但新实验、输入与预测须单独核验。普通规则的已测亚毫秒开销和历史API约秒级返回只提供数量级背景，不能把2秒审议设定冒称为本次实测规则/模型成本。
