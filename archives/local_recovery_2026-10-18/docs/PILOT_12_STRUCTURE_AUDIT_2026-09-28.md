# 12 种任务结构的首轮审核与离线实验

日期：2026-09-28。状态：作者侧机器／语义初审和合成机制复核；**尚无人类领域双审、正式 benchmark 样本或真实设备实验**。设计先于结果写在 [12 种结构稿](PILOT_TASK_STRUCTURES_V0.1_2026-09-28.md)。机器结果为 `homecoord_bench/results/pilot_structure_reaudit_20260928.json`；运行入口为 `homecoord_bench/audit_pilot_structures_v01.py`，不发模型 API 请求。

## 总体结论

12 种结构均逐项检查。**7 种有部分可执行试验，5 种目前只有设计、没有合格 episode。**“部分可执行”并不等于通过正式数据准入。现有可运行试验均缺至少一项独立审核、物理／设备依据或完整配对条件。独立仓库已按哈希清单迁入 HomeCoord 源码及限定的存档结果；完整离线回归为 **162 项通过**。

## 本轮发现并修正的实验错误

M03 首次组合 C1 与 EV 任务时，EV 工具目录沿用旧格式，没有严格验证所需的 `tool_name`；全部策略的 EV 动作被误判为 `tool_not_authorized`。补齐工具契约后才保存结果。随后发现缺乏舒适任务有效期会让某规则在长时间充电结束后仍发起制冷；为此给该任务增加显式前置条件与**人工命令周期截止时间**，并在报告里保留其合成性质。新增两项回归检查锁定四臂只变化“能源任务到达时刻／容量”，以及强基线不会因接口错误失效。不能把这两次修正前的假失败当研究发现。

M02 新增的完成触发语义在任务实际完成后才发布后继任务，不把预定持续时间作为未来已知的释放时间。三项回归检查覆盖完成时刻、前驱失败时不释放、依赖环拒绝及合成条件下的策略取舍。当前不支持烘干在洗衣完成前进行信息有限的预约；这仍是 M02 的下一项设计问题。

C2 复算与存档的唯一结构差异是新代码在每条输出加了 `heat_rate_c_per_s=0.025` 元数据。剔除此后来字段后 100/100 条结果一致，数值结论没有变化。迁移清单与源文件 SHA256 见 `docs/LOCAL_SOURCE_MIGRATION_MANIFEST_2026-09-28.json`。

## 研究判断与下一道门槛

这批复核说明模拟器能区分同设备冲突、容量超限、三 Agent 排序和消息迟到；也再次说明**强规则在当前已知约束任务上足够强**。M03 的新结构增加了耦合度，但没有留下强规则不能解决的稳定缺口。当前没有资格把“12 种任务”写成已完成的数据集，更不能计算顶会论文级整体胜率。

下一步按证据价值排序：①让 B01、B03、M01、M02、D01 的任务契约与来源接受独立审核；②为 D01 补同一入室事件的提前预约／临界通知配对，并用同等信息的确定性规则比较；③给 M02 补完成前预约的信息可见性，并比较不预约与有限预约；④取得 B02／M04 所需的联合环境轨迹。若设备资料短期拿不到，相应题保留在明确标注的 `synthetic_stress` 子集，不能混入现实物理主结论。无需为了填满 12 行而先调用大量模型 API。

本轮未请求人工审核者意见，也没有模型 API 调用、真实设备测量或 GitHub 上传。
